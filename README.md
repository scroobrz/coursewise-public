# Coursewise (public version for software testing portfolio)

This is a public repo derived from a private version of the same project containing proprietary code. Coursewise is a product I am building for my IEL entrepreneurship course, and the main private repo consists of a full-stack web application.

To keep the proprietary code private, this repo is a copy of just some core backend code, containing mostly authentication logic (registration, email verification, password login, magic-link two-factor and trusted devices); the frontend has been stripped out completely and certain preexisting features have been removed from the backend. So, what's left in this public repo is a REST API capable of performing authentication services.

For my software testing portfolio, I will extend the current backend test suite to be more thorough, as well as building and testing a basic/prototype version of a reviews & discussions feature (which will inform the development of a full version of said feature in the private repo).
